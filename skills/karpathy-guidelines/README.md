# Karpathy Guidelines

This folder is the repo-local Codex adaptation of the upstream project:

- Source repo: `https://github.com/forrestchang/andrej-karpathy-skills`
- Local upstream clone: `archive/tooling/skill-staging/andrej-karpathy-skills`

The upstream project was packaged for Claude Code. This wrapper exposes the core guidance as a plain Codex `SKILL.md` so it can be copied into a Codex skills directory or referenced from this repo's skill staging area.

## Files

- `SKILL.md`: Codex-ready version of the behavioral guidance
- `../andrej-karpathy-skills`: untouched upstream clone for reference

## Usage

If you want to install it into your active Codex skills set, copy this folder into your Codex skills directory as `karpathy-guidelines`.
