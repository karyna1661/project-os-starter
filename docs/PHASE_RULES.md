# PHASE_RULES

## Objective
Strengthen the starter's collaboration model without widening it into a domain-specific platform.

## Allowed In This Phase
- adding project-agnostic coordination templates
- defining repo-visible collaboration rules
- clarifying how agents and collaborators should consume shared context
- improving documentation for current-phase execution discipline

## Not Allowed In This Phase
- domain-specific product assumptions
- stack-specific defaults as the main path
- heavy workflow automation that replaces human judgment
- duplicating the full private Project OS inside the shared repo

## Deferred
- specialized templates for specific industries or stacks
- integrations with external planning tools
- automation that mutates coordination files automatically

## Guiding Principle
Export only the minimum shared execution surface collaborators need in order to act safely.
