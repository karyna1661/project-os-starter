# BUILD_CONTEXT

## Current Phase
Phase 1 - First Dependable Workflow Loop

## Goal
Establish one narrow, reviewable, high-value workflow loop that proves the project can create dependable value before broader expansion.

## Key Decisions
- The current phase prioritizes one honest workflow over a framework.
- Work should stay local-first and inspectable.
- Later-scale ideas should be deferred instead of partially implemented early.

## Current State
- The project OS structure exists.
- Phase specs, review rules, verification structure, and compaction protocol are in place.
- Shared Execution Context (SEC) is available as the repo-visible collaboration layer.

## In Progress
- Tightening the starter so collaborative repos can export minimum viable execution context.
- Keeping the starter project-agnostic while supporting multi-developer and multi-agent work.

## Guardrails
- Do not turn the starter into a stack-specific generator.
- Do not duplicate the entire private planning system inside the repo.
- Keep SEC lightweight and execution-oriented.
