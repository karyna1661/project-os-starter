# DEFINITION_OF_DONE

## General

A task is complete only when:

- the intended behavior or document change exists
- the work stays within approved scope
- the result is committed or ready to commit
- the happy path has been checked
- obvious follow-up work is recorded instead of hidden

## Starter-Specific Checks
- project-agnostic design is preserved
- examples teach the standard without overfitting to one domain
- linked docs and guidance remain consistent

## Collaboration Checks
- SEC files are updated if the work changed what others should do
- proof or sanity-check evidence exists when milestone claims depend on it
